# Peregrinaje: Challenges

> Source-available project. Viewing and studying the source code is permitted. Redistribution, public forks, derivative works and modified public releases are prohibited without explicit written permission from the author.

An extensive overhaul mod for Warhammer: Vermintide 2.

Peregrinaje is one of the largest and longest-running overhaul projects created for the Vermintide 2 Modded Realm.

The mod introduces progression systems, new gameplay mechanics, custom content, balance changes, quality-of-life improvements and long-term character development.

After more than five years of continuous development, this repository serves as the official source archive and development history of the project.

## Main Features

- Hero progression system.
- Weapon progression system.
- New weapons, talents, boons, traits and properties.
- Custom challenge systems.
- Expanded gameplay mechanics.
- Random curses and events.
- Custom scoreboard.
- Numerous balance, QoL and gameplay improvements.
- Support for larger groups and repeat heroes.
- Integration of mechanics inspired by Campaign, Chaos Wastes and Weaves.

## Project Philosophy

Peregrinaje is designed around long-term progression and earning power through gameplay.

Many systems are intentionally interconnected. Features such as progression, rewards, balance changes and unlock systems are not independent components and are intended to work together as part of the overall experience.

While individual mechanics may appear simple in isolation, the mod has been developed as a cohesive ecosystem over years of iteration, balancing and community feedback.
