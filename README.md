# Peregrinaje: Challenges

An extensive overhaul mod for Warhammer: Vermintide 2.

Peregrinaje transforms the Vermintide 2 experience through progression systems, new gameplay mechanics, custom content, balance changes, quality-of-life improvements and long-term character development.

After more than five years of development, this repository serves as the official source archive and development history of the project.

## Main Features

- Hero progression system.
- Weapon progression system.
- New weapons, talents, boons, traits and properties.
- Custom challenge systems.
- Expanded gameplay mechanics.
- Random curses and events.
- Custom scoreboard.
- Numerous balance, QoL and gameplay improvements.
- Support for larger groups and repeat heroes.
- Integration of mechanics inspired by Campaign, Chaos Wastes and Weaves.

## Project Philosophy

Peregrinaje is designed around long-term progression and earning power through gameplay.

Many systems are intentionally interconnected. Features such as progression, rewards, balance changes and unlock systems are not independent components and are designed to work together as part of the intended experience.
