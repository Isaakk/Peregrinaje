# Peregrinaje: Challenges

> Source-available project. Viewing and studying the source code is permitted. Redistribution, public forks, derivative works and modified public releases are prohibited without explicit written permission from the author.

An extensive overhaul mod for Warhammer: Vermintide 2.

Peregrinaje began as a small collection of ideas and gradually evolved into a complete alternative way to experience Vermintide 2 within the Modded Realm.

Over more than five years of continuous development, the project has grown into a large-scale overhaul featuring progression systems, custom mechanics, new content, balance changes, quality-of-life improvements and countless gameplay additions.

This repository contains the official source code and development history of the project.

## Features

- Character progression system.
- Weapon progression system.
- New talents, boons, traits and properties.
- New gameplay mechanics and challenges.
- Random curses and events.
- Reworked reward systems.
- Custom scoreboard.
- Numerous balance changes and quality-of-life improvements.
- Support for up to eight players.
- Support for duplicate heroes.
- Features and mechanics inspired by Campaign, Chaos Wastes and Weaves.
- Hundreds of additions, adjustments and improvements accumulated throughout years of development.

## Design Philosophy

Peregrinaje is built around progression, experimentation and replayability.

The goal is not simply to make Vermintide 2 easier or harder, but to provide players with new ways to develop their heroes and equipment while facing increasingly demanding challenges.

Many systems are designed to interact with each other. Progression, rewards, balance decisions and gameplay mechanics were developed as parts of a single experience rather than as isolated features.
